# SolidWorks-Parts
A collection of miscellaneous and Vice Machine Parts CAD models created in SolidWorks.

## Parts Included:
- **L-Bracket:** Structural support component.
- **Shaft:** Standard transmission shaft.
- **Pulley:** Designed for belt-driven systems.
- **Flange:** Connecting pipe/shaft rim.
- **Vice Machine:** A heavy duty precision mechanical workholding device.
